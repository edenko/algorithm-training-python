# 03. 스택 · 큐 · 힙

> 목표: 자료구조의 동작과 비용을 설명하고, 순서·우선순위가 있는 문제를 독립적으로 모델링한다.

## 핵심 개념

- **스택**: 마지막에 넣은 원소를 먼저 꺼낸다(LIFO). Python에서는 `list.append()`와 `list.pop()`을 사용한다. 괄호 짝짓기, 되돌리기, 단조 스택에 활용한다.
- **큐**: 먼저 넣은 원소를 먼저 꺼낸다(FIFO). `collections.deque`의 `append()`와 `popleft()`를 사용한다. 대기열과 BFS에 활용한다. 리스트의 `pop(0)`은 원소 이동 때문에 O(n)이다.
- **힙**: 가장 작은 원소를 우선 꺼내는 우선순위 큐다. `heapq.heappush()`와 `heappop()`은 O(log n), 최솟값 확인은 O(1)이다. 최대 힙은 숫자의 부호를 바꾸거나 별도 기준을 구성한다.

## 단계별 훈련

### 1단계 · 기초 구현

자료구조별 삽입·삭제 과정을 손으로 추적하고 빈 자료구조와 원소 하나인 경우를 확인한다.

- [ ] 백준 9012 괄호 — 여는 괄호와 닫는 괄호의 대응
- [ ] 백준 2164 카드2 — 큐의 앞과 뒤 조작
- [ ] 백준 1927 최소 힙 — 삽입과 최솟값 삭제
- [ ] 프로그래머스 같은 숫자는 싫어 — 직전 원소와 비교

### 2단계 · Lv.2 패턴

- [ ] 올바른 괄호, 괄호 회전하기 — 짝과 회전 후 유효성 검사
- [ ] 기능개발, 프로세스, 다리를 지나는 트럭 — 시간과 대기 순서 모델링
- [ ] 주식가격, 뒤에 있는 큰 수 찾기 — 단조 스택에 남기는 인덱스의 의미
- [ ] 택배상자, 과제 진행하기 — 보조 스택과 상태 복원
- [ ] 더 맵게 — 최소 원소 두 개를 반복해서 결합

### 3단계 · 실전 응용

- [ ] 프로그래머스 이중우선순위큐 — 두 힙을 쓸 때 삭제된 값의 동기화 방법 설명
- [ ] 프로그래머스 디스크 컨트롤러 — 도착 순서와 작업 우선순위 구분
- [ ] 미풀이 문제를 제한 시간 안에 풀고 자료구조 선택과 시간복잡도를 설명

## 점검할 것

- [ ] 단조 스택에 각 원소가 최대 한 번 들어가고 나오는 이유를 설명한다.
- [ ] 힙이 전체 정렬된 배열이 아니라 최솟값을 빠르게 꺼내는 구조임을 설명한다.
- [ ] 동률, 빈 큐, 마지막 원소, 동시에 발생하는 이벤트를 검증한다.
