# 05. 이분탐색 · DP

> 목표: 단조성을 이용해 답의 범위를 줄이고, 반복되는 부분 문제를 상태와 점화식으로 표현한다.

## 핵심 개념

- **이분탐색**은 정렬된 범위에서 조건을 만족하는 경계를 찾는다. 구간의 의미와 답이 존재하지 않는 경우를 먼저 정한다. `bisect_left`는 삽입 가능한 가장 왼쪽 위치를 반환한다.
- **매개변수 탐색**은 최솟값·최댓값 문제를 “이 값이 가능한가?”라는 판별 문제로 바꾼다. 가능 여부가 단조롭게 변해야 하며 판별 함수의 비용을 포함해 O(판별 비용 × log 탐색 범위)를 계산한다.
- **동적 계획법(DP)**은 중복되는 부분 문제의 결과를 저장한다. 상태의 의미 → 초기값 → 점화식 → 계산 순서 → 정답 위치 순으로 설계하고 시간·공간 복잡도를 계산한다.

## 단계별 훈련

### 1단계 · 기초

- [ ] 백준 1920 수 찾기 — 정렬과 이분탐색, 중복·없는 값
- [ ] 백준 1463 1로 만들기 — 상태와 이전 상태의 관계
- [ ] 백준 2579 계단 오르기 — 연속 선택 제한을 반영한 상태
- [ ] 작은 입력을 손으로 채우고 경계값과 초기값을 확인

### 2단계 · Lv.2 패턴

- [ ] 프로그래머스 멀리 뛰기, 2 x n 타일링 — 점화식과 나머지 연산
- [ ] 땅따먹기, 가장 큰 정사각형 — 2차원 상태와 갱신 순서
- [ ] 숫자 변환하기 — DP와 BFS의 적용 조건 및 비용 비교
- [ ] 퍼즐 게임 챌린지 — 단조 판별 함수와 최소 가능 값 탐색
- [ ] 반복문 기반 DP와 메모이제이션을 비교하고 각각의 종료 조건을 확인

### 3단계 · Lv.3 응용

- [ ] 입국심사, 징검다리 건너기 — 탐색 범위와 판별의 단조성 설명
- [ ] 정수 삼각형, 등굣길 — 경계와 도달 불가능한 상태 처리
- [ ] 도둑질, 거스름돈 — 원형 제약과 경우의 수 중복 처리
- [ ] N으로 표현 — 연산 횟수에 따른 상태 집합 설계
