### 탐색과 최단 경로

- **DFS** — 재귀와 스택을 활용한 연결 요소 및 격자 탐색
- **BFS** — 큐를 이용한 거리 계산과 최단 경로 탐색
- **DFS/BFS 응용** — 안전 영역, 미로, 벽 부수기 등 다양한 조건의 탐색
- **백트래킹** — 선택과 복원을 통한 순열 및 조합 탐색
- **다익스트라** — 우선순위 큐를 활용한 가중치 최단 경로와 경로 추적

### 현재 학습: 해시와 정렬

`dict`, `set`, `Counter`를 활용하는 해시 문제와 `sorted`, `sort`, 정렬 키를 활용하는 문제를 순서대로 연습할 예정입니다. 자세한 학습 계획은 [해시·정렬 학습 노트](00-document/02-해시-정렬.md)에서 확인할 수 있습니다.

### 학습 방법

각 주제의 문서는 개념 이해, 기초 구현, Lv.2 패턴, Lv.3 응용 순서로 구성했습니다. 입력 크기와 시간복잡도를 먼저 확인하고 독립적으로 풀이한 뒤, 막힌 문제는 해설을 덮고 재구현합니다. 다음 날과 7일 뒤 재풀이하며 핵심 문제는 Java로도 구현합니다.

## 실행 방법

Python 3 환경에서 저장소를 내려받은 뒤 원하는 파일을 실행합니다. 문제에 따라 표준 입력을 직접 입력하거나 파일로 전달할 수 있습니다.

```bash
python3 01-graph-search/05-dijkstra/01-shortest-path.py
```

```bash
python3 01-graph-search/05-dijkstra/01-shortest-path.py < input.txt
```

문제별 입력 형식과 풀이 내용은 각 소스 파일을 참고하세요. `previous/`에는 이전 학습 과정에서 작성한 풀이가 보관되어 있습니다.
